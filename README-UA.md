# Fomo Chumz — сайт мінту та стейкінгу

Готові сторінки: `/`, `/stake/`, `/docs/`. Дизайн адаптований до телефонів; зображення колекції включені. Поточний режим — до запуску: без адреси NFT транзакції заблоковані, статистика не вигадується.

## Запуск на Vercel

Завантажте цей проєкт у свій GitHub, імпортуйте репозиторій у Vercel. Framework: Other. Build command: `npm run build`. Output directory: `dist`. Node.js 22 або новіший. Додано vercel.json. Для локальної перевірки: `npm ci`, `npm run build`, `npx serve dist`. Не відкривайте HTML через file://.

## Єдиний файл налаштувань

Відредагуйте `dist/site-config.js`, потім перевикладіть сайт:

| Поле | Що вказати |
| --- | --- |
| nftAddress | Адреса розгорнутого FomoChumz v3 |
| stakingAddress | Можна залишити порожнім: сайт читає NFT.staking() |
| deploymentBlock | Номер блока створення контракту; потрібен для пошуку застейканих NFT |
| walletConnectProjectId | Project ID перенесено без змін із skeleton-main(6).zip; звірте його у Reown Dashboard |
| twitterUrl | Офіційний https://x.com/… колекції |
| openseaUrl | Офіційний https://opensea.io/collection/… |
| rpcUrl | RPC Robinhood Chain; за потреби замініть на публічно доступний endpoint з CORS |

Приватні ключі та seed-фрази в сайт не додаються. Project ID WalletConnect — публічний ідентифікатор, не приватний ключ. У Reown додайте фінальний домен до списку дозволених доменів. Використано Reown AppKit + EthersAdapter, темну тему та салатовий акцент, як у наданому skeleton-main(6).zip. Project ID скопійовано точно; його працездатність і дозвіл нового домену потребують перевірки у вашому Reown Dashboard. На iPhone можна відкрити сайт у браузері гаманця.

Мережа: Robinhood Chain, chainId 4663, gas ETH. CHUMZ: `0xC8D832DAcBD3eBfC1001fA6383aB99dBf07a13f5`.

## Поведінка

- 8 888 NFT, 20 000 CHUMZ/NFT, довічний ліміт карбування 100 на адресу.
- Мінт: перевірка балансу → approve точної суми за потреби → mint.
- 70% оплати — спалювання згідно з burnMode контракту; 30% — пул винагород. Відправлення на dead address не зменшує totalSupply токена; документація це розрізняє.
- Стейкінг: вибір NFT → дозвіл NFT-контракту → stake. Unstake доступний незалежно від таймера claim.
- 30 CHUMZ за годину на NFT, облік за секундами. Перший claim через 24 години після першого stake гаманця; наступний через 24 години після успішного claim. Новий stake/unstake не скидає цей таймер.
- Коли вільні кошти пулу закінчуються, нове нарахування зупиняється. Борг за цей час не накопичується. Раніше зароблені винагороди резервуються. Поповнення — через approve + fundRewards, не звичайним переказом токенів.
- 30% одного мінту = 6 000 CHUMZ, цього вистачає на 200 годин для одного NFT. Для безперервних винагород потрібне додаткове фінансування. 24-годинний claim не означає автоматично профінансовані 24 години.
- Публічні лічильники читаються без гаманця. Власні NFT шукаються через Blockscout, застейкані — через події контракту; при недоступності індексатора є ручне введення ID з перевіркою власника on-chain.

## Сумісність і запуск

ABI у `src/FomoChumz.json` і `src/ChumzStaking.json` відповідають підготовленим контрактам v3. Якщо інтерфейс зміниться, оновіть ABI й виклики в `src/app.js`, потім виконайте build. Простого додавання адреси стороннього контракту недостатньо.

Перед відкриттям мінту звірте tokenAddress, NFT.staking(), режим спалювання, decimals і наявність усіх 8 888 JSON-метаданих за вашим IPFS CID. Перевірте реальний мінт, stake, unstake і claim на розгорнутих контрактах. Поточна перевірка сайту не є live-тестом контрактів чи аудитом токена CHUMZ.

Офіційні X/OpenSea URL наразі не надано — кнопки мають чесний стан «coming soon». Мінт відкривається функцією адміністратора контракту, не перемикачем на сайті.

## Файли

`dist/` — готова статична збірка; `src/` — код; `build.mjs` — збірка; `package-lock.json` — зафіксовані залежності. `npm run build` перезбирає тільки JavaScript, зберігаючи ваш site-config.js та зображення.
